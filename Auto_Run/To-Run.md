## For Windows:

```bash
dotnet run auto.cs -- client.cs --hidden 
```
or , 

```bash
dotnet run --file auto.cs -- client.cs --hidden 
```

## For Mac & Linux: 

```bash
sh auto.sh  client.js --hidden 
```

**Note: auto.sh no longer need extra auto.js, it can generate auto.js**

## For Linux: 

```bash
python auto.py  client.py --hidden 
```
